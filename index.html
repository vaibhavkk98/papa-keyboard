Timbre

Timbre is the sound character of the keyboard. In the JRK661, pressing Timbre and entering a code selects sounds like harmonium, piano, flute, or strings.

How to use: select one of the 13 built-in songs, then switch to Sequence to see the melody blocks. Click any block to preview that phrase on the keyboard.

Visual Sequence

Sequence view: each block is a playable phrase. When the live player runs, active phrases light up and show the current musical step.
